## 实际遇到的问题与处理

- 未登录请求返回 HTTP 200，错误为 `2048:你必须登录`；配置登录态后实际复现 `2048:服务器忙,请稍后重试`。两者分别处理。
- 还出现过 HTTP 503 空响应和重复跳转。程序在“服务器忙”或空 503 时每隔 1 秒重试；使用 CookieJar 接收同站更新的 Cookie，用于后续请求和跳转。
- 搜索请求明确带页码，使用普通查询地址和浏览器常用请求头。正常检查成功后等待 60 秒；重试属于同一轮检查，暂停和退出可取消重试。
- 搜索结果外层作者、日期属于主题；只使用 `__P` 中的回复作者、PID、正文和时间。跨页从最新结果向后补查，失败不推进原进度。
- JSON 格式连续失败两次后使用普通网页；网页的主题日期不能代替回复时间，因此从已经验证的缓存或对应发言详情补全时间。
- 按主题 ID 和 PID 去重，兼容多个主题的 PID 0；飞书和弹窗链接均指向对应主题与发言。保留原待确认提醒、飞书队列和旧进度字段。
