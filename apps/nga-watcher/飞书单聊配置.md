# 让飞书机器人单聊提醒你

适用于已有 App ID 和 App Secret 的飞书企业自建应用。

1. 在 [飞书开发者后台](https://open.feishu.cn/app) 打开该应用，确认已添加并启用“机器人”能力。
2. 在“权限管理”中开通 `im:message:send_as_bot`（以应用的身份发消息）。
   如果接收人类型选择 **User ID**，还需开通 `contact:user.employee_id:readonly`（获取用户 user ID）。缺少时飞书会返回 `99991672`。使用 Open ID 时无需为了 User ID 开通此权限。
3. 在版本管理中发布应用及权限变更；将你设为应用的可用用户。接收人须属于该企业；若发布或权限需要审批，先在飞书后台完成审批。
4. 在监控器点击“飞书设置”，填写 App ID、App Secret，选择接收人类型并填写对应值。优先选择“飞书邮箱”，填写你的飞书企业账号邮箱；也支持 `ou_` 开头、属于当前应用的 Open ID，以及当前企业的 User ID。
5. 点击“发送单聊测试”，在飞书中查看该机器人的私聊。测试会实际发送一条消息，但不会改动监控进度，也不会自动保存配置。
6. 勾选“启用飞书单聊通知”，点击“保存设置”。此后新检测到的发言会逐条发送；本地弹窗仍然有效。

收到测试消息代表该应用已经可以向指定用户发私聊。发送权限、应用发布状态或接收人可用范围不正确时，监控器会显示飞书错误码；修正后待发送消息会继续重试。电脑必须保持运行且联网，手机收到提醒还取决于飞书的通知设置。

飞书配置与待发送队列各自保存在本机用户目录，关闭本地提醒不会取消飞书待发送消息。关闭飞书开关会暂停发送，重新启用后恢复。不要使用群机器人的 Webhook 填写 App ID 或 App Secret。

接口参考：[发送消息](https://open.feishu.cn/document/server-docs/im-v1/message/create)。
