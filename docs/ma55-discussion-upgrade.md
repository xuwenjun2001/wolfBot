# 55线新讨论：规则修订与多周期流程

2026-09-14。对应 `ma55-breakout-pullback`。论坛发言是待检验的策略假设，不能直接视为胜率证据。

## 本次落地

公共参数增加可选 `discussion_v2` 日线规则；历史参数缺少 `rule_set` 时仍解释为 `daily_v1`。当前公共配置不会随代码升级自动改写。在页面选择并保存版本后，新事件使用新版，已有事件继续按冻结参数评估。使用现有 JSONB 参数，无新增数据库迁移。

| 环节 | 原版日线 | 讨论版日线 |
| --- | --- | --- |
| 短期趋势 | MA5 > MA10 > MA20 | 另要求三线较上一有效K线上升，5/10和10/20间距都扩大 |
| 突破 | 前收盘≤前MA55，当日收盘>当日MA55 | 相同；日MA233暂不独立入池 |
| 涨幅与实体 | `(收盘/开盘−1)×100 ≥ body_pct`，默认3% | 保留实体要求，额外要求`(收盘/前收盘−1)×100 ≥ change_pct`，默认5% |
| 放量 | 当日量/此前5根有效日K均量≥1.5 | 相同，比较个股自身，不含突破日；参数可调整 |
| 回踩 | 收盘距MA55在−3%～+1%，量≤突破日80% | 页面切入新版时预设下限−1%、上限沿用当前值；最低价距MA55不得低于下限，收盘须≥MA55，再检查收盘距离及缩量 |
| 支撑破坏 | 仅按短均线趋势失效退出 | 回踩日最低价跌破容忍下限，即使收回也使该事件失效，次日不能复活 |
| 时效 | B+1、B+2两个交易日 | 暂沿用，用于对照研究；不声称适用于所有周期 |

三线间距扩大、允许1%的日内刺穿是本次明确化的研究口径，不是原帖给出的唯一公式。严格不破可将下限设为0%。日线MA55包含当日收盘，因此回踩判断只能收盘后得到；不能当作当天盘中可成交的止损价或买点。

证据分开展示突破涨幅与实体涨幅；复盘识别“未收回55线”和“跌破容忍下限”，支撑失效仍保留收益观察记录。平台新增多周期观察指引，原可编辑公共指引保留。

## 推荐流程

`大盘与行业环境 → 个股风险筛选 → 突破级别确认 → 次级别回踩确认 → 仓位与失效线 → 持仓管理 → 事后复盘`

1. **环境先行。** 固定沪深300/相应市场指数及所属行业基准。候选研究规则可用指数收盘与MA55关系、MA20斜率、上涨家数占比划分环境。下跌时先观察，出现止跌、均线收回和行业同步修复再评估新开仓。环境缺数据标记未知。“大盘下跌时抄底胜率最高”没有样本依据，不能写为系统结论。
2. **标的质量。** 100–500亿元采用总市值口径，可作为可选范围；另核查成交额、停牌/ST/退市风险、连续涨跌停与重大公告。机构持仓须引用已公布报告及披露日期，主线题材应有当时可得的行业强度或人工理由。市值、资金流、换手率不能证明“不是庄股”。不得用今日市值或后来披露的机构持仓筛历史股票。
3. **分开两条路径。** 日MA55突破→60分钟回踩作为较晚的日线确认路径；60分钟MA55突破→15分钟回踩作为较早的探索路径。分别记录事件身份、突破周期、入场周期、确认时间及风险预算。小周期右侧确认相对日线也可能很早，不能一律称为纯左侧。
4. **233只是提示。** 15分钟MA233覆盖58.25小时，60分钟MA233覆盖58.25个A股交易日，日MA233约46.6个五交易日周，均不等于上一级55。即使用220替代233，低周期平均了所有低周期收盘，高周期仅采样高周期收盘，权重也不同。遇到233突破应切上一级直接读取MA55确认；周K还要处理节假日和未结束周。若日MA233提示的是周线突破，应先确认周MA55，再按周线→日线观察回踩；继续下钻60分钟只能作为额外的早期路径，不能把开仓基准偷偷改成日线。
5. **入场确认。** 先发生突破，之后才接受次级别回踩：最低价触及预设均线邻域、未破坏容忍下限，已收盘K线收回MA55，再核验缩量回踩/反弹放量、上方压力和止损距离。冻结规则，不能见到走势后改“附近”“不破”的含义。未收盘K线只作预警。
6. **风险约束仓位。** 先定义单笔允许亏损，再由入场价与失效价距离计算股数，向下取整到交易单位，受单股/行业/总仓位上限约束。更早的分钟路径使用更小的初始风险预算，比例由回测决定。不能因没背离无限加仓，也不能越跌越加替代失效退出。

## 加仓、做T与退出

- 固定最初开仓的突破周期，不能为延迟止盈不断切换。基础仓、T仓、当日买入量、可卖数量分别记录。
- 次级别回踩MA55收回，再突破上一个已确认高点，才进入加仓/T仓判断；新高出现前不得预判后续背离。
- 顶背离需要两个可比较且已确认的价格高点，后者价格更高，对应MACD DIF或正柱峰值更低，必须明确采用哪种指标。摆动高点依赖右侧K线确认，信号时间不能回填到高点当时；不同周期不能拼接，历史不足不能当成“没有背离”。
- 确认顶背离时提示减T仓；没有背离时，仍需趋势与风险/总仓位预算允许才能保留或加仓。A股T+1下，只能卖已有可卖底仓，不能假定当日新买可即买即卖。
- 初始突破周期MACD正柱连续下降可定义为“动能减弱预警”，例如3根已收盘正柱逐根变低，长度为待验证参数。结合价格新高失败、支撑破坏或移动止损决定分批退出。缩柱不等于价格顶背离，也不等于确定顶部。
- 回测纳入下一可交易时点、滑点、手续费、跳空与涨跌停成交限制。日终才确认的信号，不能假定已经以当天最低价或收盘价完成交易。

## 后续自动化与验收

当前详情支持日K和分时走势，分时不是60/15分钟K线。本次大盘过滤、历史市值/机构数据、分钟回踩、MACD背离和仓位管理仍是人工核验流程。

自动多周期策略需要统一复权的15/60分钟与日/周K、交易时段聚合（午休不能串成连续交易小时）、完整性与收盘标记、指数/行业同时间截面、时点市值及公告。状态机按实际收盘顺序推进；分钟缺口只能“不可评估”，不能补成无量K线或拿旧K确认。缓存按证券/周期/复权/版本隔离。

对照原版、严格日线版、日线→60分钟、60分钟→15分钟四组，用时间外样本分牛熊/震荡环境比较假突破率、最大不利波动、交易后收益、回撤、换手、成本及跌停无法退出的情况。现有B+1/B+2收盘收益是事件研究，不是可执行策略收益；样本不足不承诺某条路径胜率更高。

建议顺序：严格日线对照样本 → 分钟数据与事件链 → 加仓/止盈观察，每步独立验证。
