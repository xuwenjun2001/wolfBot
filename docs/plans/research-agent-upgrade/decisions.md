## 实施前需要在对应步骤回答的问题

- S02：资料再分发权限、开发/保留公司划分、人工标注负责人及可复验保存位置。
- S04—S05：新任务版本和现有研究 run 的关系；哪些内容存数据库，哪些存本地对象；旧报告兼容方式。
- S08：Docling 在本机/开发部署环境的安装、资源、中文准确性与定位支持；服务复用还是隔离进程。
- S10：中文检索基线、分块策略和指标；是否确有必要加 embedding/reranker。
- S14：现有 SSE 到 AG-UI 的映射是否足够；无宿主需求时可先不装完整 UI 框架。
- S19：独立评审模型/人工样本可用性，真实调用预算及可比较基线。

这些是对应步骤内要完成的工程判断，不能被解释成每次都必须向用户请求许可。只有缺少无法从仓库/已有授权推断的信息时才询问。
