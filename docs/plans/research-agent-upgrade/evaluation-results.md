# 财报研究 Skill 的配对评测

S19 使用冻结的四家公司开发集，比较完整能力基线与一个离线候选。候选未达质量门，已冻结保留原版。最终保留的用户核查确认已登记，但缺答计入分母后质量门未过；当前状态以 [progress.md](progress.md) 为准。本页不会把单元测试或历史 S03 不同能力、不同模型的结果当成改进幅度。

## 预登记合同

模型沿用当前 `gpt-6.1-sol`、reasoning=high，reviewer 沿用 S12 同模型独立调用的 8/8 校准回执。每家公司一个新逻辑研究任务、40 次工具、20 分钟；任务内允许局部修复，不能另开任务重置失败预算。四个开发基线、四个候选配对，选择与冻结后两个保留验收，共预登记最多 10 个真实模型任务。重复次数为每公司每版本 1 次；不能声称稳定性 3×3 或总体统计显著。

### 数值校验缺口与第二批合同

第一批 `paired-20261020-01` 的五粮液在 40 次工具内只有 2/9 数值、0/3 问题，24 次工具拒绝；原生摘要使用“营业收入（元）”等行内单位，当前校验器漏识别，多次 `FACT_UNIT_UNVERIFIED` 后预算耗尽。美的也已出现同类错误。这是 S12 校验覆盖缺口，不能靠 prompt 要求模型绕过或换单位制造通过。

2026-10-20 在读取保留集前登记修复：精确识别当前指标行的金额单位；其他行单位、冲突单位、缺少期间列和调整前后列继续拒绝。先保存旧实现的失败测试，再修复并回放真实原表。第一批四公司基线保留，不生成该批候选，不与修复后结果计算 Skill 提升。

修复后的 `paired-20261020-02` 重新冻结同一份开发资料、评分、模型和 **40 次 / 20 分钟**单任务预算，再运行四基线、一个候选四配对、冻结后两保留。S19 总上限因此从原登记 10 个增加为 14 个真实任务（第一批 4 + 第二批 10），是明确的组件修复和新实验，所有失败耗用仍计入总账，不是失败任务重开重置预算。实际次数及冻结后开启时点按最终记录列示。

先跑开发基线，再从失败轨迹生成一个候选；候选为应用研究提示词的实验覆盖，执行副本存放在忽略的 campaign 目录，最终唯一候选的无答案文本另存 [可恢复 fixture](../../../fixtures/company-research/skill-candidate-v1.json)。HTTP 接口和生产 Worker 不接受用户输入的 prompt 覆盖；不自动发布 `.pi` Skill 或改 registry/lock。报告 method 保存实际 skillVersion/skillSha256，旧报告兼容读取且 hash 不变。

冻结的原件、S07 解析回执、开发题/参考、人工确认批次、rubric、reviewer prompt/校准、源码、模型和预算全部进入 protocol.json。候选配对时核对合同完全一致，只有 Skill 文本不同。baseline/candidate 各只运行一次；网关失败、partial、工具失败和无 usage 请求也保留。runner 不把参考答案传给生成器，评分在生成后独立进行。

第二批 130 份冻结源码的原始字节另存 `paired-20261020-02/frozen-source.zip`，SHA-256 `fb0282bdd4e44b4cd5dfc53d38aaf91648a9a448d50840d8128e795f816a83c2`；manifest 绑定 protocol hash。跨平台复验先按受控归档恢复，再核对每份 bytes，避免 Git 换行转换使同一次配对身份漂移。此归档不包含环境文件、凭据或原始资料。

## 评分和选择

数值沿用 S02：每公司两期 6 金额和 3 增幅，共开发 36 项；缺答计错。金额按原表最后显示单位的一半容差，增幅容差 0.01 个百分点，计算使用十进制整数表示。问题为分母，共 12 个；一个问题只有全部相关结论受支持、必要数字正确、无硬门错误才完成。公司整体 completed 单独列出，不能用局部完成冒充整份报告完成。

全部实质 claims 进入支持率分母；零结论不可计算。生产的独立 reviewer 回执与确定性发布检查分别复验，引用存在不能代替语义支持。开发数值有既有人工确认，新报告语义评分仍是经有限校准的同模型独立调用，不能称新增人工准确率或不同模型独立判断。首轮按第一次 check_coverage 的公司状态登记，任务内修复后的最终结果另列；没有调用覆盖检查就标未知/未完成。

硬门任一已知失败阻断选择，不能靠平均分抵消。开发阈值保持数值 ≥95%、支持 ≥90%、问题完成 ≥80%；候选必须通过并在配对结果中有可说明的收益，回退保留原版也是有效实验结果。最终冻结记录绑定 protocol、候选、两组结果和选择理由，之后才读取外部保留集。保留结果只验收，不继续用其问题调优。

Wilson 95% 区间复用现有统计工具，报告原始分子/分母。一个公司内的金额、问题和 claims 相关，区间只作描述；4 家/2 家与一次运行不能证明面向全部上市公司的效果。耗时、已知 Token、未知请求、失败和工具次数逐次保存；无价格回执时费用 unknown，每成功成本不能写成 0。
